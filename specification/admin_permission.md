アカウント関連
- ユーザーの発行
- ユーザーの削除
- ユーザーの無効化、有効化
- ユーザー名変更
- ユーザーアイコンリセット
- ユーザーのlogin_token更新(既存のsessionを全破棄)
- ユーザーの最大ストレージ容量変更
- ユーザーの1ファイル当たりの最大容量の変更
- ユーザーのストレージ使用量の確認
- ユーザーのファイル量の確認
- ユーザーのログイン履歴の閲覧(session情報も)
- デフォルトの有効期限の変更
- 最大有効期限の変更 (デフォルト無制限)

補足
- ユーザー無効化時は新規ログインを禁止する
- ユーザー無効化時は既存のsessionを全破棄してよい
- login_token更新時は旧login_tokenを即時無効化し、既存のsessionを全破棄する

データ関連
- 非公開ファイルはあくまでそのデータ、ファイル名、種類が見えるだけで、ファイル自体にはアクセス不可
- ファイルの公開、非公開設定 (強制非公開も + ユーザー側非公開ファイルを公開は不可 + サムネ等も不可(他人のファイルなので))
- ファイルの有効期限編集(ユーザー制限無視)
- ファイルの削除
- ファイルの名前、種類、アップロードユーザー、ファイルサイズ、アップロード日時の確認

補足
- public = true のファイルは未ログイン閲覧を許可できる
- public = false のファイルは所有者または管理者のみアクセスできる
- processing 中のファイルは URL 自体は保持するが、ダウンロード可否は status で制御する
