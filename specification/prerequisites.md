# 前提条件

---

# 1. システム構成

* 本サービスは Node.js を実行基盤とする
* サーバーは単一インスタンスで動作する（スケールアウトは考慮しない）
* ffmpeg をサーバー上で実行可能とする

---

# 2. アーキテクチャ方針

* フロントエンドとバックエンドは分離する
* バックエンドは REST API として実装する
* 認証はトークンベース（セッション管理）とする

---

# 3. ファイル処理方針

* アップロードはストリーム方式で処理する
* アップロード中に重い処理（変換・圧縮等）は行わない
* ファイル保存完了後に非同期処理として実行する

---

# 4. 動画処理

* 動画処理には ffmpeg を使用する
* ffmpeg は子プロセスとして起動する
* 同時実行数は制限する（最大1〜2程度）
* 実行優先度は低く設定する

---

# 5. ストレージ

* ファイルはサーバーのローカルストレージに保存する
* 将来的に外部ストレージ（S3互換等）へ移行可能な設計とする

---

# 6. パフォーマンス方針

* CPU負荷の高い処理は同期的に実行しない
* APIレスポンスを最優先とする
* バックグラウンド処理はキューで制御する

---

# 7. 対応範囲

* モダンブラウザ（最新のChrome系）を対象とする
* モバイル向けUIも含め対象とする

---

# 8. PWA前提

* manifest と service worker を提供する
* 事前キャッシュ対象は UI シェルと静的アセットに限定する
* ファイル一覧やファイル本体はオフラインキャッシュの前提にしない
* API データ取得は network-first を基本とする
