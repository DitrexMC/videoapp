# (Modern Design)
- pwaを必須に
- UI層、通信層、サーバー層と、確実にレイヤードアーキテクチャを採用してください。
- フロントのwebページは、htmlもそうですが、可能な限り、共通化、ファイル分けを徹底してください。

## PWAの扱い

- PWA化の対象はフロントUI層とユーザー向けの基本画面のみ
- ファイル一覧、ファイル詳細、アップロード進捗、セッション状態は毎回サーバーから取得する
- 大容量ファイルや一覧データをオフライン保存対象にしない
- service worker は静的アセットのキャッシュを主目的にする
- API通信は network-first を基本にする

## レイヤー方針

- UI層は表示と状態遷移のみを担当する
- 通信層は API 呼び出し、認証ヘッダ制御、エラーハンドリングを担当する
- サーバー層は認証、権限判定、アップロード制御、ファイル配信を担当する
